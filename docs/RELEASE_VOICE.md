## v1.3 更新内容（本版）

### 快捷刷新：点悬浮窗棋盘 = 点「更新」

悬浮窗右列的「更新」按钮只有 23dp 高，实战中不好点。本版在「语音设置 → 悬浮窗快捷操作」里新增开关 **「快捷刷新」**：

| | |
| --- | --- |
| 开关位置 | 主页「语音设置」→ 悬浮窗快捷操作 → 快捷刷新 |
| 默认状态 | **关**。关闭时点棋盘仍是上游原有的「切换候选着法 / 变招」，完全不改动原行为 |
| 开启后 | 点悬浮窗中间那块 171×185dp 的迷你棋盘，等同于点一次右列「更新」按钮 |
| 实际动作 | 走与「更新」按钮**完全相同**的链路：翻转走子方 → 重建 FEN → 清空旧建议 → 重新查开局库 / 启动引擎分析 → 状态提示「棋局已更新」 |
| 生效时机 | 改完开关立即生效，正在显示的悬浮窗无需重启、无需重新授权录屏 |
| 手动摆棋 | 不受影响：手动模式下点棋盘仍用于选子 / 走子 / 删子，快捷刷新不会抢走点击 |

实现上不是加一个空壳按钮：点击经悬浮窗面板的 `onAction` 派发为 `OverlayAction.FLIP_TURN`，由识别线程串行执行与「更新」按钮共用的那一段业务代码；开关状态每次渲染从配置现读，设置页热改即时生效。点击决策抽成纯函数并配了 JVM 单测，另有一条真实点击链路测试验证「关 → 变招 / 开 → 刷新 / 手动 → 不抢点击」。

> 说明：本功能与语音无关，但按需求集中放在本分支自建的「语音设置」页内；主页仍然只有一个入口，不占用原作者布局。

## v1.2 更新内容（上一版）

### 1. 朗读文本去掉坐标，只读纯中文着法
v1.1 真机能读了，但朗读内容会带上界面里的 UCCI 坐标，例如「炮二平五 (h2e2)」「兵三进一 (g3g4)」。本版在朗读前剥离括号坐标，**只读「炮二平五」「马三进二」「炮五平七」这类中文着法**。悬浮窗界面上显示的坐标保持原样（上游原有信息，未改动）。

### 2. 「读哪些内容」可自由勾选
软件不只能给出支招建议，还会显示开局库着法、对方回合预案、态势评估、状态提示等信息。本版在「语音设置」里做成 **5 个可勾选项**，勾哪些就读哪些，可单选也可任意组合：

| 勾选项 | 朗读内容 | 默认 |
| --- | --- | --- |
| 支招建议（含备选变招） | 引擎给出的建议着法，如「炮二平五」 | 开 |
| 开局库着法 | 命中开局库时的着法 | 开 |
| 对方回合预案 | 「若对方走 X，我方应 Y」 | 关 |
| 态势评估 | 胜率 / 红方优势劣势 / 搜索深度 | 关 |
| 状态与异常提示 | 「引擎思考中」「轮次可能识别有误」「无可用着法」等 | 关 |

默认仍只读支招建议与开局库着法（与 v1.1 行为一致），需要更多内容再自行勾选。**「仅支一招（1 变）时朗读、支两招三招不朗读」沿用 v1.0 约定，未改变**；总开关「语音提示」关闭后一切不读。勾选「态势评估」时，会在着法后附带读出评估信息（如「炮二平五，红方优势 32，深 20」）。

### 3. 主页只留一个「语音设置」入口
为尽量少破坏原作者布局，主页不再平铺 5 个语音控件，只保留 **一个「语音设置」入口**。点进去才是本分支的全部语音功能：总开关、TTS 引擎选择、朗读内容勾选、试听、诊断记录开关、导出日志（v1.3 起另有「快捷刷新」开关）。主页其余设置行（识别引擎、思考制式、预计算、检查更新等）均为上游原样。

### 4. 导出诊断日志支持自选路径
点「导出诊断日志」会弹出**系统文件选择器**，自己选保存位置后写入 `.md`（Markdown 文档）。取消则提示「已取消」；写入失败自动回落到系统「下载」目录并提示。无需任何存储权限。

### 5. 诊断日志改进
- 修正版本号首字母丢失（此前导出显示 `oice-1.0-…`，应为 `voice-1.0-…`），并新增「语音模块版本」标识；
- 高频的「去重 / 打断 / 排队」等重复事件聚合为「连续 N 次」，日志不再刷屏；
- 新增记录：识别到的内容类别、该类别是否勾选及跳过原因、**文本清洗前后对比**（可核对坐标剥离是否生效）、最终朗读文本。

## 语音功能说明（沿用 v1.0 / v1.1）

- **语音提示开关**（默认开）：关闭后完全不朗读，不影响支招计算、悬浮窗、连线等原有行为。
- **语音提示引擎**（默认「跟随系统」）：列出设备已安装的 TTS 引擎供选择，选中项持久化。基于 Android 原生 `TextToSpeech`，**未引入任何第三方语音 SDK**。
- **支一招自动朗读**：仅当支招档位为 1 招时生效，支两招、三招不朗读。新结果会打断上一段，同一着法不重复读；音量跟随系统媒体音量。
- **试听**：设置页点一下即用当前选中引擎朗读一句中文，不受支招档位、开关、去重影响，用来快速分清是「设备 TTS 通路不通」还是「支招触发没走到」。
- **语音诊断日志**：只记录本次新增的语音功能链路，**不记录**棋盘识别、FEN、引擎搜索、完整对局、性能数据等任何原有功能数据（v1.3 的快捷刷新开关不属于语音链路，同样不写入）。默认开，可在设置页关闭。
- **建议排查顺序**：先「试听」→ 有声音说明 TTS 通路正常；再开一局看支一招是否朗读 → 仍不读就「导出诊断日志」，看时间线里类别勾选、`onInit` / `setLanguage` / `speak` 哪一环被跳过或报错。

## 两个安装包怎么选

| 文件 | 说明 |
| --- | --- |
| `*_armv8-dotprod-release.apk` | **推荐**。需 ARMv8.2 dotprod 指令集（骁龙 855 / 麒麟 990 / 天玑 1000 及以上） |
| `*_armv8-release.apk` | **兼容变体**，供不支持 dotprod 的老机器 |

仅支持 arm64-v8a 架构的 64 位 Android 设备（minSdk 26 / Android 8.0+）。

## 使用前须知

- **签名为 debug 签名**：本分支不持有上游官方发布密钥，产物可直接安装，但**不能覆盖安装官方签名版**（需先卸载官方版）。
- **升级旧版请注意**：CI 每次在全新构建机上生成 debug 签名密钥，各版本签名**很可能不一致**。若安装时提示「应用未安装 / 签名冲突」，请先卸载旧版再装本版（卸载不影响语音设置以外的数据）。
- **不具备官方版完整能力**：上游受版权保护的 ONNX 识别模型与桔库开局库**未随本分支分发**，按上游设计缺失时识别自动回退 YOLO、连线降级纯引擎模式。
- **不在官方版本安全线内**：上游自 v3.2 起对官方 Release 包启用签名指纹核验，本分支的 debug 签名包不受该线覆盖，请自行核对来源。
- 系统需已安装并启用至少一个支持中文的 TTS 引擎；若系统无中文语音数据，可在「系统设置 → 语言和输入 → 文字转语音」中安装。
