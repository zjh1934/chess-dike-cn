## v1.1 修复：上一版支招完全不朗读

上一版（voice-1.0）编译与单测均通过，但真机实测**一次都读不出来**。根因在语音播放器（TTS）内部，与支招计算、悬浮窗、识别均无关：

| # | 问题 | 修复 |
| --- | --- | --- |
| 1 | TTS 初始化失败后 `ready` 永远为 false，且排队时就写死去重标记，导致同一着法此后被永久吞掉、`resetDedup()` 也解不开 → **一次失败即全程静音** | 初始化失败改为可重试；去重标记只在 `speak()` 真正成功后写入；复位时一并清排队与失败态 |
| 2 | 全程未调用 `setLanguage(Locale.CHINESE)`，中文着法交给引擎默认语言，`speak()` 静默失败 | 初始化成功后显式设置中文并校验返回值，缺中文语音数据时做语言兜底 |
| 3 | 构造异常与 `speak()` 返回值被丢弃，失败无任何痕迹、无法自愈 | 全链路记录返回值与回调，失败可重试 |

同时新增 `UtteranceProgressListener`，把 onStart / onDone / onError 写进诊断日志——这是判断「到底有没有真正出声」的硬证据。

## v1.1 新增：试听与语音诊断日志

- **试听**：设置页语音区域新增「试听」按钮。点一下就用当前选中的引擎朗读一句中文，**不受支招档位、开关状态、去重影响**。用来快速分清是「设备 TTS 通路不通」还是「支招触发没走到」。
- **语音诊断日志**：新增独立诊断通道，**只记录本次新增的语音功能**（开关/引擎配置、TTS 构造与引擎枚举、`onInit` 状态、`setLanguage` 结果、`speak()` 返回值、去重/排队/打断决策、朗读开始/完成/错误、试听事件、服务生命周期）。**不记录**棋盘识别、FEN、引擎搜索、完整对局等任何原有功能数据。默认开，可在设置页关闭。
- **一键导出 MD**：设置页新增「导出诊断日志」按钮，导出为 Markdown 文档（文件名 `XQDK_语音诊断_日期_时间.md`）写入系统「下载」目录，并提示文件路径。文件含设备/版本信息、逐条时间线表格与自动结论提示。测试或反馈问题时把这个 md 发出来即可定位，不必抓 logcat。
- **建议排查顺序**：先点「试听」→ 有声音说明 TTS 通路正常；再开一局看支一招是否朗读 → 仍不读就点「导出诊断日志」，看时间线里 `onInit` / `setLanguage` / `speak` 哪一环报错。

## 语音功能说明（沿用 v1.0）

- **语音提示开关**（默认开）：关闭后完全不朗读，不影响支招计算、悬浮窗、连线等原有行为。
- **语音提示引擎**（默认「跟随系统」）：列出设备已安装的 TTS 引擎供选择，选中项持久化。基于 Android 原生 `TextToSpeech`，**未引入任何第三方语音 SDK**。
- **支一招自动朗读**：仅当支招档位为 1 招时生效，支两招、三招不朗读。朗读内容是「建议」后面的着法本身（如「炮二平五」），不含「建议」二字。新结果会打断上一段，同一着法不重复读；音量跟随系统媒体音量。

## 两个安装包怎么选

| 文件 | 说明 |
| --- | --- |
| `*_armv8-dotprod-release.apk` | **推荐**。需 ARMv8.2 dotprod 指令集（骁龙 855 / 麒麟 990 / 天玑 1000 及以上） |
| `*_armv8-release.apk` | **兼容变体**，供不支持 dotprod 的老机器 |

仅支持 arm64-v8a 架构的 64 位 Android 设备（minSdk 26 / Android 8.0+）。

## 使用前须知

- **签名为 debug 签名**：本分支不持有上游官方发布密钥，产物可直接安装，但**不能覆盖安装官方签名版**（需先卸载官方版）。
- **升级 voice-1.0 请注意**：CI 每次在全新构建机上生成 debug 签名密钥，两个版本的签名**很可能不一致**。若安装时提示「应用未安装 / 签名冲突」，请先卸载 voice-1.0 再装本版（卸载不影响语音设置以外的数据）。本版起新增的试听与诊断日志在首次安装后即可用。
- **不具备官方版完整能力**：上游受版权保护的 ONNX 识别模型与桔库开局库**未随本分支分发**，按上游设计缺失时识别自动回退 YOLO、连线降级纯引擎模式。
- **不在官方版本安全线内**：上游自 v3.2 起对官方 Release 包启用签名指纹核验，本分支的 debug 签名包不受该线覆盖，请自行核对来源。
- 系统需已安装并启用至少一个支持中文的 TTS 引擎；若系统无中文语音数据，可在「系统设置 → 语言和输入 → 文字转语音」中安装。
