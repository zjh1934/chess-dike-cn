# 象棋迪克 XQDK · 支招语音提示版

基于上游 [Silva6c/chess-dike](https://github.com/Silva6c/chess-dike) 的分支版本，新增「支招结果语音播报」。源码与构建配置见本仓库 `main` 分支，构建流水线为 `Build-Voice`。

## 本次新增

- **语音提示开关**（设置页，默认开）：关闭后完全不朗读，不影响支招计算、悬浮窗、连线等原有行为。
- **语音提示引擎**（设置页，默认「跟随系统」）：列出设备已安装的 TTS 引擎供选择，选中项持久化。基于 Android 原生 `TextToSpeech`，未引入任何第三方语音 SDK。
- **支一招自动朗读**：仅当支招档位为 1 招时生效，支两招、三招不朗读。朗读内容是「建议」后面的着法本身（如「炮二平五」），不含「建议」二字。新结果会打断上一段，同一着法不重复读；音量跟随系统媒体音量。

## 两个安装包怎么选

| 文件 | 说明 |
| --- | --- |
| `*_armv8-dotprod-release.apk` | **推荐**。需 ARMv8.2 dotprod 指令集（骁龙 855 / 麒麟 990 / 天玑 1000 及以上） |
| `*_armv8-release.apk` | **兼容变体**，供不支持 dotprod 的老机器 |

仅支持 arm64-v8a 架构的 64 位 Android 设备（minSdk 26 / Android 8.0+）。

## 使用前须知

- **签名为 debug 签名**：本分支不持有官方发布密钥，`app/build.gradle.kts` 自动回退 debug 签名，产物可直接安装，但**不能覆盖安装官方签名版**（需先卸载官方版）。
- **不含官方版权资产**：上游的 ONNX 识别模型与桔库开局库受版权保护、不随源码分发，本包未内置。按上游设计，缺失时识别自动回退 YOLO、连线降级为纯引擎模式，不影响基本使用。
