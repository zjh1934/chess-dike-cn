## v1.3 更新内容

### 1. 快捷刷新：点悬浮窗棋盘 = 点「更新」键

悬浮窗右列的「更新」键太小不好点，而识别偶发偏慢，等对方走完想立刻出着时，正要手动点「更新」触发计算。本版在「语音设置 → 悬浮窗快捷操作」里加了「快捷刷新」开关，**默认开**：

- **开启后**，点悬浮窗中间那块大棋盘，效果与点右列「更新」键**完全相同**——同一段代码，立即重新计算这一步该走什么，悬浮窗提示「棋局已更新」。装上即可用，不用任何设置。
- **关闭后**，点棋盘恢复上游原有的「切换候选着法 / 变招」。
- 手动摆棋模式下点棋盘仍然用于选子 / 走子，不会被抢走；改开关立即生效，悬浮窗不用重启。

### 2. 安装包签名固定：以后新版本直接覆盖安装

此前流水线每台新构建机都自动生成一把新签名钥匙，导致各版本签名互不一致，升级必须先卸载。**从本版起流水线改用一把固定钥匙出包：v1.3 及之后的所有版本之间可以直接覆盖安装，不用再卸载**（应用包名保持与上游一致，没有变过）。从 v1.2 及更早版本升级到本版，因旧版签名不同，仍需最后卸载一次旧版。本 Release 的 CI 构建日志里打印了 APK 签名指纹，前后两版指纹一致即证明可覆盖安装。

## 历史版本（沿用）

- **v1.2**：朗读文本去掉坐标只读纯中文着法（如「炮二平五」）；「读哪些内容」5 项可自由勾选（默认只读支招建议与开局库着法）；主页收敛为一个「语音设置」入口；导出诊断日志支持系统文件选择器自选路径；日志聚合与版本号修正。
- **v1.1**：修复支一招完全不朗读（TTS 初始化失败不可逆、未设中文语言等根因），新增试听与语音诊断日志（只记语音链路）。
- **v1.0**：支一招建议用系统 TTS 朗读；支两招三招不读；语音开关与引擎选择。

## 两个安装包怎么选

| 文件 | 说明 |
| --- | --- |
| `*_armv8-dotprod-release.apk` | **推荐**。需 ARMv8.2 dotprod 指令集（骁龙 855 / 麒麟 990 / 天玑 1000 及以上） |
| `*_armv8-release.apk` | **兼容变体**，供不支持 dotprod 的老机器 |

仅支持 arm64-v8a 架构的 64 位 Android 设备（minSdk 26 / Android 8.0+）。

## 使用前须知

- **签名为本分支固定的 debug 签名**：本分支不持有上游官方发布密钥，产物可直接安装，但**不能覆盖安装官方签名版**（官方版需先卸载）。**v1.3 起各版本之间签名一致，可互相覆盖安装。**
- **不具备官方版完整能力**：上游受版权保护的 ONNX 识别模型与桔库开局库**未随本分支分发**，按上游设计缺失时识别自动回退 YOLO、连线降级纯引擎模式。
- **不在官方版本安全线内**：上游自 v3.2 起对官方 Release 包启用签名指纹核验，本分支的 debug 签名包不受该线覆盖，请自行核对来源。
- 语音功能需系统已安装并启用至少一个支持中文的 TTS 引擎；若系统无中文语音数据，可在「系统设置 → 语言和输入 → 文字转语音」中安装。
