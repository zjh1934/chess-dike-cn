## v1.4 更新内容

### 1. 点棋盘才识别：不点＝零识别、零推理、零支招、零朗读

以前是「自动连续识别」：一开连线就持续抓帧、跑识别、跑引擎，画面一变就重算，长时间用发热明显。本版改成**完全由你点一下说了算**：

- **不点悬浮窗中间的棋盘**：只保留最近一帧画面，不识别、不推理、不查开局库、不出招、不朗读，帧循环零推理空转；顶部状态行显示「待点棋盘」。
- **点一次棋盘**：启动**一轮**识别会话——抓当前画面 → 识别 → 多帧确认 → 重建 FEN → 查开局库 / 皮卡鱼引擎支招 → 按语音设置播报。确认完成立即收场，回到静止态。
- 一轮迟迟确认不了（棋盘被遮挡 / 识别失败）10 秒后自动收场并提示「再点一次棋盘」，不会无限期烧 CPU。
- 语音设置页的「点按识别」开关**默认开**；关掉后点棋盘退回旧版「切换候选着法 / 快捷刷新」行为，但**依然不会自动连续识别**（本版不提供恢复自动识别的开关）。手动摆棋模式下点棋盘仍然是选子 / 走子，不受影响。
- 右列「更新」「悔棋」「闪电出着」等按钮仍是显式手动操作，按原语义工作。

### 2. 包名固定：`com.xqdk.chess`，以后一律不改

- `applicationId` 在构建脚本里写成显式常量锁定为 **`com.xqdk.chess`**，与 v1.3 / 上游官方保持同一应用身份。
- CI 新增**包名门禁**：出包后用 `aapt` 校验每个 APK 的 `applicationId`，不是 `com.xqdk.chess` 直接让构建失败。
- 配合 v1.3 起启用的固定签名钥匙（仓库 Secret `DEBUG_KEYSTORE_B64`），**v1.3 → v1.4 及之后各版本之间可直接覆盖安装，不用卸载**。安装包的签名指纹可在 CI 构建日志里核对。

## 历史版本（沿用）

- **v1.3**：悬浮窗快捷刷新（点棋盘 = 点「更新」键，默认开）；安装包签名固定，各版本可覆盖安装。
- **v1.2**：朗读文本去掉坐标只读纯中文着法（如「炮二平五」）；「读哪些内容」5 项可自由勾选（默认只读支招建议与开局库着法）；主页收敛为一个「语音设置」入口；导出诊断日志支持系统文件选择器自选路径；日志聚合与版本号修正。
- **v1.1**：修复支一招完全不朗读（TTS 初始化失败不可逆、未设中文语言等根因），新增试听与语音诊断日志（只记语音链路）。
- **v1.0**：支一招建议用系统 TTS 朗读；支两招三招不读；语音开关与引擎选择。

## 两个安装包怎么选

| 文件 | 说明 |
| --- | --- |
| `*_armv8-dotprod-release.apk` | **推荐**。需 ARMv8.2 dotprod 指令集（骁龙 855 / 麒麟 990 / 天玑 1000 及以上） |
| `*_armv8-release.apk` | **兼容变体**，供不支持 dotprod 的老机器 |

仅支持 arm64-v8a 架构的 64 位 Android 设备（minSdk 26 / Android 8.0+）。

## 使用前须知

- **签名为本分支固定的 debug 签名**：本分支不持有上游官方发布密钥，产物可直接安装，但**不能覆盖安装官方签名版**（官方版需先卸载）。**v1.3 起各版本之间签名一致、包名一致，可互相覆盖安装。**
- **不具备官方版完整能力**：上游受版权保护的 ONNX 识别模型与桔库开局库**未随本分支分发**，按上游设计缺失时识别自动回退 YOLO、连线降级纯引擎模式。
- **不在官方版本安全线内**：上游自 v3.2 起对官方 Release 包启用签名指纹核验，本分支的 debug 签名包不受该线覆盖，请自行核对来源。
- 语音功能需系统已安装并启用至少一个支持中文的 TTS 引擎；若系统无中文语音数据，可在「系统设置 → 语言和输入 → 文字转语音」中安装。
