
## 节奏与度量

1. 先发 1 篇介绍文，再发 1 篇安装教程，间隔 2~3 天；第 3 篇开始补教学向。
2. 每篇末尾引导到 Release 页自取安装包，不做站内下载引导。
3. 仓库侧配合：description 与 topics 已铺检索关键词（`COLD_START` 发布后可按实际搜索词再调 topics）。
4. 度量只看**本仓库**的 star / fork / release 下载短期增长；不指望上游热度导流（见 `UPSTREAM.md` 第 1 节）。
