<details>
<summary>展开看这一版改了什么</summary>

- **根因**：合法性检查只管「多认了子」，不管「少认了子」。漏一个车（车 2→1）或红车认成红卒，在旧校验里**都是合法局面**，v1.22 单帧直出会直接按残缺棋盘算招 → 这就是瞎指挥
- **修法**：拿上一次确认的局面当锚，把这一帧里孤立漏检的子补回、把同阵营类别混淆（车↔卒）改回去。真走子（数量不变）、被吃（跨阵营）一律不误补；新开局不按旧残局补。零额外延迟、不重抓帧、不跨帧比对
- **兜底**：修完仍是硬伤（帅将缺失等）就不建局、不支招，语音明确说「这帧有个子没认准，没敢给你出招，再点一次」，日志写明原因
- **日志**：新增「识别修补」行，写明补了几个、改了哪个类别、是否可疑，以后一眼看出招是在什么局面上算的

</details>
