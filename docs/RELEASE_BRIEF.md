<summary>展开看这一版改了什么</summary>

- **馊主意的主因**：07:58 日志 28 次点按 **28 次念的全是「（暂定）」，0 次「定着✓」**。之前为了「算出来就念」，播报挂在箭头刚画出来那一刻，而箭头用的是引擎第一条浅层搜索结果（通常 1~4 层），还没算完就念了 —— 快（平均 0.32 秒）但招很浅
- 现在：**定着 / 开局库 / 预判命中立刻念**；其余等 1 秒质量窗口且搜索深度≥8 才念；**2.5 秒硬预算必有声音**，绝不静默。延迟会从 0.3 秒变成 1~2 秒左右，换的是招法质量
- **第二个原因**：28 次里 10 次画面被裁掉了多认的子，以前只按置信度丢，可能丢错真棋子，引擎按缺子局面算 → 再深也是馊主意。现在拿上一帧比对，上一帧就在的真棋子优先保住，优先丢背景误检
- **重复点同一局面**：重念上一招，不重新浅算一遍，也不会让引擎按「我方又走一步」算（日志里隔 8 秒两次都念「炮1退1」就是这情况）
- 日志新增「招法质量」行：写明念的是定着✓ / 开局库 / 较深PV、深度多少、等了多久；「数量规范化」行写明延续性保住几个真子
