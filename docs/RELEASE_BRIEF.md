**v1.24** · 点一下只算「点之后新采的那一帧」；不再把对方刚走的一步撤销回上一手。

> v1.23 直接覆盖安装（同一把固定签名），不用卸载、不丢配置。

安装包就在下面 **Assets** 区，点开即可下载（不用往下翻）：

- `armv8-dotprod-release.apk` — **推荐**，新机器
- `armv8-release.apk` — 老机器兼容版

<details>
<summary>展开看这一版改了什么</summary>

- **取帧**：点一下先把录屏缓冲区里「点之前」残留的帧全部丢弃，再强制重新采一帧；日志里帧来源固定是「点击后新采帧」（只有 ROM 静止不产帧时才走兜底）
- **不再回退上一局面**：v1.23 会把漏检的子按上一盘补回空格，结果对方真走了一步时棋盘被改回上一手 → 你感觉「他完全没在算我点了之后的画面」。这版**一个空格都不补**，只纠正同格类别读错（车卒不分）
- **认全是真实走子才建局**：日志写明起点 / 终点 / 吃子统计；只看到子凭空消失、没有新落子或被吃痕迹，就判定「没认全」→ 不建局不支招，语音明确说再点一次，绝不按错局面或旧局面瞎指挥
- **引擎每次都是全新起点**：把当前这一帧的棋子摆法生成全量 FEN 发给 `position fen`，不带历史着法、不重放开局（与原作者同一口径）

</details>
