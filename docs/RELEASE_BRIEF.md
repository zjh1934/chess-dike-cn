<details>
<summary>展开看这一版改了什么</summary>

- **「第一种不能用、选了自动跳第二种」**：那是识别引擎 ONNX / YOLO。ONNX 模型受版权不随包，每次启动 0ms 加载失败就回退 YOLO，配置却还存着 ONNX，连线页又按运行态回填 → 选了又跳回。本版直接摘掉这个用不了的选项：配置、连线页、悬浮面板三处都固定 YOLO
- **「有时管用有时不管用」**：悬浮面板「引擎」芯片一点就切到 ONNX，顺手把棋盘状态清空，紧接着点棋盘必然识别失败；另有抓帧重试的竞态会让会话静默卡 12 秒。本版芯片改只读、重试单一时钟、窗口用尽必收场并给提示
- **「有时瞎指挥」**：v1.16 第一帧合法就建局，而合法性门槛不查「少没少子、和上一步对不对得上」，误检/过渡帧容易混过去按错局面支招。本版改成**连续两帧一致**才建局，再用「与上一局面是否说得通」兜底；可疑帧一律不支招
- 额外延迟只多一帧识别（约 0.1 秒），不是以前那种等好几秒的多帧确认
- 箭头出现即播、面板锁定、红黑锁定、固定签名、极简 Release 正文，全部保留

</details>
