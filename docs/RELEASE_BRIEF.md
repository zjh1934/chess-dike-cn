<summary>展开看这一版改了什么</summary>

- **不是红黑切换导致的**：03:26 诊断里最后一次真出声是 03:21:47，切到黑是 03:25 之后的事。切换只是你注意到它哑了的时间点
- **真因**：系统 TTS 服务掉线。程序每次都判定"要念"（决策 25 次）、也调了打断，但 `speak` 再没 SUCCESS、`onStart` 一次都没有；旧代码只看"调用返回成功"，不看**系统有没有真出声**
- **切黑后更彻底**：朗读器进了不可恢复的 shutdown 态，连朗读入口都进不去，而日志还写「⑤ 语音播报」「已出招·已播报」—— **日志在说谎**
- 现在：念完 1.5 秒没收到系统"已出声"回执就判定掉线 → 丢弃失效实例 → 重新绑定 → 补念一次；朗读前也会自动自愈，不再永久静默
- 日志按真实回执写：没出声就写「已出招·已交TTS(待朗读回执)」，绝不写"已播报"；新增「朗读回执」「朗读无回执」「TTS重建」行
- 顺手修：失败提示不再用会封死共享朗读器的试听接口；状态文案刷屏降噪（原占 154/600 行，把「我方选择」等关键行挤没了）
