- **选 ONNX 不再自动跳回 YOLO**：连线页切回来时以前按运行态回填、还把回退值写回配置，形成不可逆跳回。现在按你的配置回填、失败只提示不改写，并把加载失败的具体原因写进诊断日志

- **哈希按钮没动**（只是要解释，见下方说明）；上游识别/支招机制、双模型、固定签名全保留

</details>

**「哈希」是什么**：不是文件校验码，是象棋引擎的**记忆容量**（置换表，单位 MB）。面板上点一下在 256 → 512 → 1024 → 2048 循环。它让引擎记住已经算过的局面、少重复算；开大了要多吃手机内存、更容易发热，对这种几秒一步的快棋帮助有限。**默认 256 就够用，一般不用动它。**
