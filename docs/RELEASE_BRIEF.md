**v1.25** · 回到原作者源码，只加一个功能：**自动把支招读出来**。

> v1.24 直接覆盖安装（同一把固定签名），不用卸载、不丢配置。

安装包就在下面 **Assets** 区，点开即可下载（不用往下翻）：

- `armv8-dotprod-release.apk` — **推荐**，新机器
- `armv8-release.apk` — 老机器兼容版

<details>
<summary>展开看这一版改了什么</summary>

- **主体换回原作者代码**：连线识别、连续 3 帧确认、轮次推断、开局库、引擎搜索、悬浮面板全部用上游 v3.4 源码原样，之前 v1.4~v1.24 的点按档、单帧直出、识别修补、面板开关、增强诊断**全部删除**
- **只加语音**：上游自动识别、自动支招；算定的那一招用中文自动念出来（如「炮二平五」）。不念暂定着法、不念对方回合预案、不动别人棋子、同一局面同一招只念一次
- **没有开关**：语音恒开，不需要进设置；上游原有的设置页原样保留
- **保留的仓库基建**：包名 `com.xqdk.chess`、固定签名、CI 出包、检查更新指向本仓库 Release 页 —— 这些只为能覆盖安装和自动发版，不影响软件行为

</details>
