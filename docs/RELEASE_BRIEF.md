<details>
<summary>展开看这一版改了什么</summary>

- **补齐原作者的双模型**：上一版用回上游源码却漏了发版时的资产注入，一直只有 YOLO。现在 CI 从上游公开 `assets` 预发布页把两个 ONNX 模型注入 APK，sha256 逐字节校验，出包后逐个 APK 校验「里面真有两个模型」。模型不进 git（与上游一致）
- **主体换回原作者代码**：连线识别、连续 3 帧确认、轮次推断、开局库、引擎搜索、悬浮面板全部用上游 v3.4 源码原样，之前 v1.4~v1.24 的点按档、单帧直出、识别修补、面板开关、增强诊断**全部删除**
- **只加语音**：上游自动识别、自动支招；算定的那一招用中文自动念出来（如「炮二平五」）。不念暂定着法、不念对方回合预案、不动别人棋子、同一局面同一招只念一次
- **没有开关**：语音恒开，不需要进设置；上游原有的设置页原样保留
- **没动桔库**：上游缺失时本来就会自动降级纯引擎模式；包体约 92MB，不撑到上游的 163MB
- **保留的仓库基建**：包名 `com.xqdk.chess`、固定签名、CI 出包、检查更新指向本仓库 Release 页 —— 只为能覆盖安装和自动发版，不影响软件行为

</details>
