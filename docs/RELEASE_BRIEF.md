<summary>展开看这一版改了什么</summary>

- **默认**：我方支招（如「炮二平五」）仍只自动读一次；对方回合的「若对方走X，我方应Y」现在也自动读一次。两类各按局面去重、互不顶掉
- **念的是纯中文着法**：不念面板上附带的字母坐标；预案应手按「对方走完后」的盘面校验，不念已经不成立的应手
- **点一下重播**：点悬浮面板上「建议 X」或「若对方走X 我方应Y」那行文字，就把当前这句再念一次；点「变着」切到新候选，也把新那招再念一次。350ms 防抖，暂停/面板关掉不念
- **没动的**：红黑锁定、点小棋盘更新轮次、双模型、固定签名、哈希按钮（解释见完整文档）
- 上游 3 帧确认 / 自动识别 / 引擎定着全保留

</details>
